Requester Debug Steps
You need to open 3 terminals to debug requester
1. Term-1(GO-FT Screen)
2. Term-2(inspect screen)
3. Term-3(pause screen)

Step 1-
On second terminal enter > PATHCOM $(DEPENDING ON THE LOGIN) 
Open go-ft screen on term-1
Enter >status term *
alter inspect (set it to ON
and get the term name/id

Step 2-
Get the file name by 
#in 
#in expanded to:

$ZN02B.#PT0G2X4(file name)

Step 3-
Then on inspect term type

>inspect term ________________(term id ), file _______________(file name) then enter

Step 4- 
Put pause on screen 3 then give any command from GO-FT Screen and then check PAUSE Screen.
